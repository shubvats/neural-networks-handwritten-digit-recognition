# Neural Networks for Handwritten Digit Recognition

## Overview
This project explores neural networks for binary handwritten digit recognition using machine learning and deep learning techniques.

The implementation covers neural network architecture, forward propagation, and model predictions.

## Technologies Used
- Python
- NumPy
- TensorFlow
- Keras
- Matplotlib
- Jupyter Notebook

## Concepts Implemented
- Artificial Neural Networks
- Forward Propagation
- Dense Neural Network Layers
- Activation Functions
- Sigmoid Activation
- Model Prediction
- Binary Classification

## Project Structure
- `Neural_Networks_Handwritten_Digit_Recognition.ipynb` – Original assignment notebook.
- `neural_network.py` – Organized Python implementation.
- `requirements.txt` – Project dependencies.

## Objective
Build and understand neural networks capable of recognizing handwritten digits as a binary classification task.
